# 🩺 Heaven MentCare System  

A **Human-Computer Interaction (HCI) project** focused on providing **online mental healthcare support** through a secure and user-friendly platform.  

---

## 📖 Project Overview  
The system is designed to:  
- Enable individuals to seek mental health support online  
- Ensure confidentiality and user privacy  
- Provide an intuitive and accessible interface
